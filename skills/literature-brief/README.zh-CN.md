# Literature Brief 中文介绍

> 面向中文科研用户的零配置、多来源、可追溯文献简报 Skill。

`Literature Brief` 接收自然语言研究主题，自动完成中文术语解析、英文检索式扩展、学术来源路由、日期过滤、跨来源去重、相关性筛选和中文简报生成。它适合快速了解某一主题近期出现了哪些值得阅读的论文，而不是替代系统综述或完整的同行评议判断。

当前版本：`1.0.0-beta`  
许可：MIT

## 适用场景

- 查找某个主题最近发表或公开的论文。
- 在指定日期范围内筛选少量高相关文献。
- 默认挑选最新两篇论文并生成 ScholarPulse 风格中文简报。
- 对预印本和正式发表版本进行合并与来源追踪。
- 快速扫描 5–10 篇文献，形成课题调研起点。

不适合直接用于系统综述、Meta 分析、引用网络研究，也不用于深度解读用户已经提供的单篇论文。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 中文主题解析 | 内置天文、AI、生物医学常用中英词汇；优先使用确定性映射 |
| 联网术语核验 | 未收录或有歧义的中文术语先查询权威来源，不依赖低能力模型猜译 |
| 零配置检索 | 不要求 API Key、账号、邮箱、环境变量或本地配置文件 |
| 多来源路由 | 根据学科自动选择 arXiv、Crossref、Europe PMC、bioRxiv、medRxiv |
| 日期策略 | 默认查最近 7 天；不足时依次扩展至 30 天和 90 天 |
| 两种模式 | `brief` 默认 2 篇；`scan` 默认 8 篇 |
| 版本合并 | 合并同一论文的预印本、正式版本和跨数据库重复记录 |
| 来源监控 | 区分“成功且有结果”“成功但无结果”“请求失败” |
| 可审计筛选 | 保存全部候选、相关度、入选理由和确定性淘汰原因 |
| 证据边界 | 默认进行摘要级研判；摘要未提供的信息不会由模型补造 |

## 开箱使用

将压缩包中的 `literature-brief` 文件夹解压到支持 `SKILL.md` 的 Agent Skills 目录。Codex 的常用安装位置为：

```text
~/.codex/skills/literature-brief/
```

然后直接用自然语言调用，例如：

```text
使用 $literature-brief 查找最近关于智能体记忆的两篇论文，生成中文简报。
```

```text
使用 $literature-brief 扫描 2026 年以来检索增强生成方向值得关注的 8 篇论文。
```

```text
使用 $literature-brief 查找土卫九相关文献，并报告每个来源是否检索成功。
```

Skill 会自动执行主题解析和检索脚本。也可以直接运行底层脚本：

```bash
python3 scripts/search_literature.py \
  --topic "智能体记忆" \
  --mode brief \
  --pretty
```

扫描模式：

```bash
python3 scripts/search_literature.py \
  --topic "检索增强生成" \
  --mode scan \
  --pretty
```

指定日期范围：

```bash
python3 scripts/search_literature.py \
  --topic "癌症免疫治疗" \
  --from 2026-01-01 \
  --to 2026-08-31 \
  --count 4 \
  --pretty
```

## 输出内容

底层脚本返回结构化 JSON，其中包括：

- 原始中文主题及其英文解析结果；
- 实际检索式、日期范围和排序策略；
- 请求来源及逐来源健康状态；
- 合并去重后的全部候选论文；
- 入选论文、入选理由和未入选原因；
- DOI、arXiv、PubMed、PMC 或出版商链接；
- 请求错误和检索窗口扩大记录。

Agent 在这些结构化结果之上生成中文简报，包括今日速览、逐篇核心内容、方法与数据、价值判断、局限与待验证点，以及检索说明。

## 来源与边界

当前保留的来源均可在不配置密钥的条件下使用：

- arXiv：计算机、数学、物理、天文及相关预印本；
- Crossref：跨学科 DOI 和出版元数据；
- Europe PMC：医学与生命科学论文、摘要和开放全文链接；
- bioRxiv：生命科学预印本；
- medRxiv：医学预印本。

公开学术接口仍可能发生临时限流或网络故障。Skill 会保留错误并继续使用其他成功来源，不会把来源失败描述为“没有论文”。

对于词表中没有的中文术语，完整工作流需要宿主 Agent 具备联网检索能力，以便核验规范英文名称、同义词及歧义。底层脚本不会擅自猜译未知中文词。

## 与 ScholarPulse 的关系

ScholarPulse 是面向固定研究方向的定时研究情报流水线；`Literature Brief` 是面向临时主题的按需检索 Skill。两者共享“少而相关、中文研判、来源可追溯”的设计方向，但运行方式相互独立。
